# Data Wrangling and Cleaning

## About the Project

This is a learning project focused on understanding data wrangling and data cleaning using Python.

In this project, I am working with an HR employee dataset to learn how to explore, understand, clean, and prepare data for further analysis.

## Dataset

**Dataset Name:** `hr_employee_messy_dataset.csv`

This dataset contains HR employee-related data and is being used to practice data wrangling and cleaning techniques.

## Tools and Technologies

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Learning Objectives

Through this project, I aim to learn:

* Understanding the structure of a dataset
* Exploring data using Pandas
* Identifying missing values
* Checking duplicate records
* Understanding and correcting data types
* Identifying inconsistent data
* Learning about outliers and their detection

## Project Files

* `Data_wrangling.ipynb` — Notebook for practicing data wrangling and cleaning.
* `outliers .ipynb` — Notebook for learning about outliers.
* `hr_employee_messy_dataset.csv` — Dataset used for practice.
